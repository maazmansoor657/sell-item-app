# Picture-to-List — Sell Items by Taking Photos

A small web/mobile-first project that lets users take photos of items (rocks, collectibles, etc.), create sale listings, and accept purchases. This repository contains a simple web UI (index.html snippet included below) and a recommended mobile/web stack for an MVP using Expo (React Native) + Firebase + Stripe.

## Features (MVP)
- Take or upload photos of an item
